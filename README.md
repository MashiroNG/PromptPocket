# PromptPocket 提示词口袋

PromptPocket 是一个为 ChatGPT 网页版优化的本地提示词管理 Chrome 插件。它可以把网页里看到的好提示词快速保存下来，并在需要时通过侧边栏、右键菜单或 ChatGPT 输入框旁的快捷浮窗直接复用。

当前版本：`1.1.11`

## 原仓库

本项目基于 SimplestPrompt fork 改造：

[https://github.com/thejohnd0e/SimplestPrompt](https://github.com/thejohnd0e/SimplestPrompt)

感谢原作者提供的轻量本地提示词收藏基础。

## 主要功能

- 提示词收藏保存在本地，不需要插件账号；可选的“增强提示词”会把选中文字发送到你配置的模型服务。
- 支持文件夹管理、拖拽排序、搜索和按文件夹筛选。
- 支持置顶提示词，置顶内容可直接出现在右键一级菜单。
- 支持置顶管理视图，可拖拽或用按钮调整置顶顺序。
- 支持快捷提示词管理，可拖拽或用按钮调整 ChatGPT 快捷弹窗顺序。
- 支持快捷提示词范围设置：全部提示词、只显示置顶、指定文件夹。
- 在 ChatGPT 网页版输入框旁显示快捷浮窗，点击后可快速插入提示词；展开本窗口的插件侧边栏时自动隐藏入口和快捷浮窗，关闭侧边栏后恢复入口，刷新网页也保持此行为。
- 选中网页文字后可出现悬浮保存按钮，也可通过右键保存。
- 保存弹窗支持修改标题、内容、保存文件夹，也可以直接新建文件夹。
- 使用提示词时可选择直接粘贴到当前输入框，或只复制后手动粘贴。
- 支持导入前预览、合并导入、覆盖导入和导入前自动备份。
- 支持 JSON 导出和数据清理工具，便于备份和去重。
- 首次打开默认亮色，支持切换深色；侧边栏和保存弹窗会沿用已保存的主题选择。
- 支持选中文字后增强提示词：保留原意和原语言，先预览，再确认替换原选区。

## 安装方式

需要 Chrome 142 或更新版本，以支持侧边栏打开、关闭事件。

1. 打开 Chrome 的 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的项目根目录，不要选择 `src/`。
5. 打开 ChatGPT 或 Gemini 网页，点击浏览器工具栏里的插件图标，即可打开侧边栏；可在扩展菜单中将图标固定到工具栏。

### 更新已安装的插件

1. 先从侧边栏导出 JSON 备份，再下载或拉取仓库最新代码，保持原安装目录不变。
2. 打开 `chrome://extensions/`，点击 PromptPocket 卡片上的“重新加载”，无需卸载插件。
3. 刷新已打开的 ChatGPT/Gemini 页面，再打开插件侧边栏。

侧边栏和保存弹窗首次打开默认亮色；手动切换主题后会记住选择。展开插件侧边栏时，同一窗口网页输入框旁的“提示词”按钮和快捷浮窗自动隐藏；关闭侧边栏后恢复按钮，侧边栏展开期间刷新网页也不会重新显示按钮。

## 快速使用

### 保存网页选中文字

1. 在网页或 ChatGPT 页面选中一段提示词。
2. 点击选区旁的“保存提示词”悬浮按钮，或右键选择 `PromptPocket 提示词口袋 -> 保存选中内容为提示词`。
3. 在弹窗里修改标题、内容和保存文件夹。
4. 点击保存后，提示词会进入对应文件夹。

### 在 ChatGPT 快捷输入

1. 先关闭插件侧边栏，再点击 ChatGPT 输入框。
2. 输入框右侧会出现 `提示词` 浮窗按钮。
3. 点击按钮打开快捷提示词列表。
4. 搜索或选择提示词，点击后会插入到当前输入框。

### 管理快捷范围

在侧边栏的 `快捷范围` 中选择：

- `全部提示词`：快捷弹窗显示所有提示词。
- `只显示置顶`：快捷弹窗只显示置顶提示词。
- `指定文件夹`：快捷弹窗只显示某个文件夹中的提示词。

设置会实时同步到已经打开的 ChatGPT 快捷弹窗。

### 增强选中的提示词

1. 在侧边栏的“选中文本处理”页找到“增强提示词”，填写“服务地址”和“访问密钥”，点击“获取模型”，再从列表中选择。默认地址是 `https://api.openai.com/v1`，其他服务请使用服务商提供的地址；模型列表通过地址后的 `/models` 获取，不会自动添加 `/v1`。获取失败会显示原因，不会填入虚假的默认模型。列表包含服务返回的模型，是否支持文字增强需要实际测试。
2. 模型下方仅保留“保存设置并测试”：先保存地址、密钥和所选模型，再用已保存的配置发送一条短消息，检查连接、鉴权和模型生成是否可用。成功后显示“测试成功 · 耗时（毫秒）”，模型名单独显示；耗时从发送测试消息到收到结果计时，包含插件消息传递，不包含配置保存和权限确认。测试可能产生少量费用；测试失败不会撤销已保存的配置。重新打开设置会回填地址和模型，密钥输入框保持为空并提示“已保存”；留空时获取模型和保存均由后台复用同一服务的已存密钥，填写新密钥后保存才会替换旧密钥。
3. “高级设置”默认收起，可修改系统提示词（模型应遵守的增强规则）、用户提示词模板、温度、采样范围和最大输出长度。用户模板必须包含 `{{text}}`，请求时会替换成选中文字；留空使用默认模板，系统提示词留空恢复内置增强规则。提示词每项最多 8000 字符。温度范围 0–2、采样范围 0–1，建议只调整其中一项；最大输出长度为 1–32768 个词元，使用 `max_completion_tokens`。数值留空不发送该参数，沿用服务默认值。保存后回填，增强和连接测试共用同一组提示词及参数；服务不支持的参数会在测试时返回失败，不会悄悄忽略。
4. 高级设置也保留免密连接、清除已存密钥及接口说明。仅本地或服务商明确说明免密时选择“不需要密钥”。获取模型和保存时请允许浏览器访问所填服务。服务须兼容 OpenAI Chat Completions 流式接口（SSE），增强和测试均使用地址后的 `/chat/completions`，不自动降级或重试。远程服务只允许 HTTPS，HTTP 仅允许 `localhost` 和 `127.0.0.1`。
5. 在 ChatGPT/Gemini 的输入框或页面中选中文字，点击选区工具条的“增强提示词”。结果逐段显示，生成期间不能用按钮复制或替换；取消、按 Esc 或离开页面会断开连接并中止后台请求。中止不保证服务商立即停止计算或计费。模型、参数和 25 秒总请求超时保持不变，流式显示不保证总生成时间缩短。
6. 完整生成并通过检查后，检查原文与增强结果，再点击“确认替换选中文本”。只替换原选区，支持浏览器原生撤销；等待期间原文变化会阻止替换。不可编辑的网页文字仅支持复制结果，不直接改页面。超时、中途断流、截断或错误会清空不完整预览并显示失败，不自动重试；取消、请求失败或配置缺失均保留原文。

访问密钥以原值持久保存在本机插件专用 IndexedDB 中，未由插件加密，浏览器重启后仍保留；密码框遮挡不等于加密。后台不向设置页返回已存密钥，不发送给网页脚本、不包含在应用内导出或备份中；复制整个浏览器资料目录仍可能带走密钥，请保护本机资料。旧版当前会话中的密钥会在读取时迁移。修改服务网站、协议或端口时会清空密钥输入，后台不会把旧密钥用于其他服务；切回原服务可继续留空复用。配置缺失、网络错误、鉴权失败和限流都会明确提示，可手动重试。

增强设计参考 [zcode-plus](https://github.com/Llliao1113/zcode-plus)，实现使用插件现有消息与选区入口，没有引入其桌面注入控制器。模型输出仍需人工检查，插件不能保证模型完全遵守语言与重写约束。

## 数据与隐私

提示词收藏保存在 Chrome 本地存储 `chrome.storage.local` 中。保存、搜索和备份不上传提示词；获取模型时会向所填服务发送密钥，测试时会将固定短文本填入已保存的提示词模板，主动点击“增强提示词”才会将选中文字填入模板。不携带聊天历史、页面全文或附件。模型服务可能收费或保留请求，请自行确认服务条款，不要在自定义提示词或选文中放入不希望外发的敏感内容。

导出数据为 JSON 文件，主要结构如下：

```json
[
  {
    "id": "folder-id",
    "name": "收件箱",
    "prompts": [
      {
        "id": "prompt-id",
        "title": "提示词标题",
        "text": "提示词内容",
        "timestamp": "2026-05-19T00:00:00.000Z",
        "sourceUrl": "https://chatgpt.com/",
        "sourceTitle": "ChatGPT",
        "pinned": true,
        "pinnedAt": "2026-05-19T00:00:00.000Z",
        "quickAt": "2026-05-19T00:00:00.000Z"
      }
    ]
  }
]
```

## 开发与维护

本项目没有第三方 npm 依赖，无需安装依赖或编译；直接按安装方式加载项目根目录。测试需要支持 `structuredClone` 的 Node.js（17 或更新版本）：

```sh
npm test
```

Windows 发布脚本示例：

```powershell
powershell -NoProfile -File scripts/release.ps1 -Version 1.1.11
```

发布需要干净的 Git 工作区、Git、Node.js 和 GitHub 凭据。脚本会生成 ZIP、创建标签，默认推送分支和标签并创建 GitHub Release；`-SkipPush -SkipRelease` 仍会创建本地标签，不是只读检查。

`npm test` 覆盖提示词处理、文件夹存储、数据迁移、保存冲突、输入注入消息、主题记忆、侧边栏与悬浮按钮联动，以及增强流式解析、取消和密钥保护；流式解析检查 LF、CRLF、CR 三种换行的逐字节分块。用 Chrome 打开 `tests/selection-enhancement.browser.html` 并点击“运行检查”，检查真实 textarea/input 的选区替换、输入事件、撤销与重做；原生编辑行为不由 Node.js 替身模拟。

待确认：`src/background.js` 仍监听旧 `quickAccessData` 存储项，但本仓库没有写入方；可能用于旧版本数据变更通知，暂时保留。

## 权限说明

- `storage`：保存提示词、文件夹、主题和快捷设置。
- `contextMenus`：创建右键菜单。
- `clipboardWrite`：复制提示词内容。
- `sidePanel`：打开插件侧边栏。
- `activeTab` 和 `scripting`：将提示词粘贴到当前网页输入框。
- `host_permissions`：支持 ChatGPT 和 Gemini 等网页上的快捷输入与文本处理。
- `optional_host_permissions`：获取模型或保存增强服务配置时申请该主机的访问权限；不会自动授予所有 HTTPS 网站权限。Chrome 的主机权限涵盖该主机所有端口，密钥仍按完整 origin 隔离。
